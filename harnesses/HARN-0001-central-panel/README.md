## Harness: Central Panel (MICTUNING P1B PDM)

### Purpose

Центральный распределительный модуль для Nissan Laurel C34 с Toyota 1UZ VVT-i. Заменяет штатный блок предохранителей/реле на MICTUNING P1B PDM. Содержит силовую шину+, шину массы (звезда), kill switch, реле стартера и инлайн-разъёмы для подключения передней, задней и салонной кос.

### System Overview

**Vehicle:** Nissan Laurel C34 + Toyota 1UZ VVT-i swap
**Harness Type:** Кастом-сборка (замена штатной проводки)
**Existing Harness:** С нуля (штатная удалена)

### Силовая топология

```
АКБ (багажник)
    |
    | 50 мм2 (+) красн.
    |
  Kill switch (салон, доступ водителю)
    |
    | F_MAIN (150-200A ANL, после kill switch)
    |
    | 50 мм2 (+) красн.
    |
  Шина + (салон, винтовая)
    |
    +---> MICTUNING P1B (80A кабель) ---> 12 каналов ---> Потребители
    |
    +---> Генератор (80A кабель, зарядный) ---> через X100
    |
    +---> Реле стартера (Bosch/ISO, 4-конт.) ---> 50 мм2 ---> Стартер (через X100)
    |
    +---> Предохранитель 10A ---> BATT ЭБУ (через X100)

  MICTUNING: масса через корпус (крепление к металлу кузова)

  Шина - (салон, винтовая) <--- звезда ---> шина - двигателя
                                           ---> шина - багажника
```

### Physical Layout

**Modules:** Центральная панель — единый физический блок в салоне (за бардачком / на консоли)

**Bundle routing:**
- Силовой ввод: АКБ (багажник) -> по левому порогу -> kill switch (салон) -> FUSE_MAIN -> BUS+
- BUS+ -> MICTUNING: ~300 мм, 80A кабель
- BUS+ -> реле стартера: ~200 мм, 50 мм2
- Панель -> X100 (передняя коса): через моторный щит, ~300 мм до разъёма
- Панель -> X200 (задняя коса): по левому порогу назад, ~200 мм до разъёма
- Панель -> X300 (салонная коса): вниз к элементам салона, ~200 мм до разъёма

**Coverings:**
- Силовые кабели (50 мм2, 80A): PET-оплетка + гофра в местах перехода
- Жгуты к инлайн-разъёмам: лента 3M Temflex 1700
- Подкапотный переход: резиновый уплотнитель (firewall grommet)

**Environment:** Салон (большая часть), переход в подкапотное пространство через firewall

2. **Длины трасс** — указаны приблизительно. Требуется обмер после определения точного расположения компонентов.
3. **CH8 Reserve** — резервный канал 30A. Куда его вывести? Добавить cavity в X100 или X300?
4. **Мощность вентилятора** — уточнить реальный ток для проверки сечения 2.5 мм2.
