## Harness: Задняя коса (Rear Harness)

### Purpose

Задняя коса обеспечивает питание задних LED-фонарей (габариты, стоп-сигналы, поворотники) и топливного насоса для Nissan Laurel C34 с Toyota 1UZ VVT-i. Выходит из центральной панели через 16-пиновый инлайн-разъём X200, идёт по левому порогу в багажник, где разветвляется к левому фонарю, правому фонарю и топливному насосу.

### System Overview

**Vehicle:** Nissan Laurel C34 + Toyota 1UZ VVT-i swap
**Harness Type:** Кастом-сборка (замена штатной проводки)
**Existing Harness:** С нуля (штатная удалена)
**Концепция массы:** Локальная звёздная масса — в косе только +12V провода, GND-пины X200 замыкаются на кузов короткими проводами (200–400 мм) в ответной части разъёма.

### Active Components

Нет. Все активные компоненты (MICTUNING, реле, предохранители) находятся на центральной панели.

### Physical Layout

**Модули:** Единая задняя коса от X200 до потребителей в багажнике.

**Маршрут прокладки:**

```
X200 (на центральной панели)
  │
  │ Основной жгут по левому порогу (~2500 мм)
  │
  ├─ bp-trunk (точка разветвления в багажнике)
  │   │
  │   ├─ Ветка к FUEL (топливный насос) ~600 мм
  │   │
  │   └─ Ветка к промежуточной точке ~600 мм
  │       │
  │       ├─ TAIL-L (левый фонарь, короткая ветка)
  │       └─ Ветка к TAIL-R (правый фонарь) ~600 мм
  │
  └─ Ответная часть X200: 7 коротких GND-проводов → точки массы на кузове (200–400 мм каждый)
```

**Приблизительные длины сегментов:**

| Сегмент | Длина (мм) | Примечание |
|---------|------------|------------|
| X200 → bp-trunk | ~2500 | По левому порогу |
| bp-trunk → FUEL | ~600 | К топливному модулю в баке |
| bp-trunk → промежуточная точка | ~600 | К точке разветвления фонарей |
| Промежуточная точка → TAIL-L | — | Левый фонарь рядом с точкой |
| Промежуточная точка → TAIL-R | ~600 | К правому фонарю |
| X200 mating GND → кузов | ~200–400 | Каждый GND-пин отдельно |

**Coverings:**
- Основной жгут (X200 → bp-trunk): PET-оплетка + лента 3M Temflex 1700
- Ветка к FUEL: лента 3M Temflex 1700
- Ветка от bp-trunk к промежуточной точке: лента 3M Temflex 1700
- Ветка к TAIL-L: лента 3M Temflex 1700
- Ветка к TAIL-R: лента 3M Temflex 1700
- В местах перехода через острые кромки кузова: дополнительная гофра

**Environment:** Салон / багажник (сухая среда, без прямого попадания воды)

### Open Questions

1. **Тип разъёмов X200, TAIL-L/R, FUEL** — конкретные part number (Deutsch DT, SuperSeal, и т.д.) не определены. Выбор влияет на BOM и cavity-нумерацию.
2. **Точные длины** — указаны приблизительно. Требуется обмер после определения точного расположения компонентов.
3. **4-pin комбо-разъём TAIL-L/R** — GND один на весь блок (пин 4), но по архитектуре у каждого потребителя свой GND-пин в X200. Если LED-блок внутри объединяет GND, то GND-пины 8–13 в X200 могут объединяться в один провод к пину 4 фонаря. Уточнить внутреннюю схему LED-блока.
